# 新增题库分片规范（AI 新增）

每个分片文件是一个 JSON 数组，元素结构如下（键名必须完全一致）：

```json
{
  "id": "jx-01",
  "module": "javax",
  "title": "题目（面试官会怎么问，30 字内）",
  "star": 4,
  "tags": ["集合", "并发"],
  "oneLine": "一句话答案（40–80 字，结论先行）",
  "s60": "60 秒口述稿（150–260 字，能直接背）",
  "s180": "展开稿（350–600 字，可分 3 段）",
  "s600": "深挖稿（600–1200 字，讲边界与取舍；没有更多可写就与 s180 相近）",
  "points": [
    { "point": "要点 1（完整句，可独立成答案）", "state": "done" },
    { "point": "要点 2", "state": "done" }
  ],
  "pitfalls": ["易错点 / 常见误区（完整句）"],
  "followUps": [
    { "q": "面试官追问（问句，15–40 字）", "a": "满分回答（120–320 字，结论先行 → 机制 → 边界）" }
  ],
  "drill": ["关键词1", "关键词2", "关键词3"],
  "provenanceNote": "AI 新增（无原文，依据公开技术资料整理）"
}
```

写作要求：

1. 每题 3–5 个要点、1–2 个坑、2–3 条追问；回答必须技术准确，不编造版本号/参数/源码行号。
2. 语言：中文口语化面试腔；禁止 markdown 标题、列表符号、代码围栏（代码只出现在文字描述里）。
3. 同一分片内 id 连续、不重复；`module` 字段必须与任务中给定的一致。
4. 文件必须是 UTF-8 无 BOM、可被 `JSON.parse` 解析的「数组」。
5. 只写任务给定的那一个文件，不修改仓库其它文件、不跑构建。

合并脚本会把上面的精简结构补齐成站点完整题目结构：`review` 全 0（未评分，verdict=draft）、`status=draft`、`codeAnchors=[]`、`source.raw=''`、`provenance.supplement=[provenanceNote]`，并打上 `aiAdded: true`（页面显示「AI 新增」徽标）。
