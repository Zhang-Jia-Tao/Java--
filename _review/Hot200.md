## LeetCode239\. 滑动窗口最大值

> 给你一个整数数组 `nums`，有一个大小为 `k`* *的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 `k` 个数字。滑动窗口每次只向右移动一位。
> 
> 返回 *滑动窗口中的最大值 *。
> 
> 

**示例 1：**

**输入：**nums = \[1,3,\-1,\-3,5,3,6,7\], k = 3
**输出：**\[3,3,5,5,6,7\]
**解释：**
滑动窗口的位置                最大值
\-\-\-\-\-\-\-\-\-\-\-\-\-\-\-               \-\-\-\-\-
\[1  3  \-1\] \-3  5  3  6  7       **3**
 1 \[3  \-1  \-3\] 5  3  6  7       **3**
 1  3 \[\-1  \-3  5\] 3  6  7      ** 5**
 1  3  \-1 \[\-3  5  3\] 6  7       **5**
 1  3  \-1  \-3 \[5  3  6\] 7       **6**
 1  3  \-1  \-3  5 \[3  6  7\]      **7**

**思路解析：双端队列维护单调递减**

```Java
class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        int n = nums.length;
        int[] res = new int[n-k+1];
        // 双端队列中存储数组下标
        Deque<Integer> queue = new LinkedList<>();
        for(int i=0; i<n; i++){
            // 移除队尾比当前小的元素
            while(!queue.isEmpty() && nums[i]>=nums[queue.peekLast()]){
                queue.pollLast();
            }
            queue.offer(i); // 存储下标
            // 移除超出窗口左边界的队首
            if(queue.peekFirst() <= i-k){
                queue.pollFirst();
            }
            // 窗口形成，记录最大值
            if(i>=k-1){
                res[i-k+1] = nums[queue.peekFirst()];
            }
        }
        return res;
    }
}
```



## LeetCode3\. 无重复字符的最长子串【华为】

> 给定一个字符串 `s` ，请你找出其中不含有重复字符的 **最长 **子串** **的长度。
> 
> 

**示例 1:**

**输入: **s = "abcabcbb"
**输出: **3 
**解释:** 因为无重复字符的最长子串是 "abc"，所以其长度为 3。注意 "bca" 和 "cab" 也是正确答案。

```Java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        int maxLen = 0;
        HashMap<Character, Integer> map = new HashMap<>();
        int left = 0;
        for(int i=0; i<s.length(); i++){
            char c = s.charAt(i);
            if(map.containsKey(c)){
                left = Math.max(left,map.get(c)+1);
            }
            map.put(c,i);
            maxLen = Math.max(maxLen,i-left+1);
        }
        return maxLen;
    }
}
```



## LeetCode438\. 找到字符串中所有字母异位词

> 
> 

**示例 1:**

**输入: **s = "cbaebabacd", p = "abc"
**输出: **\[0,6\]
**解释:**
起始索引等于 0 的子串是 "cba", 它是 "abc" 的异位词。
起始索引等于 6 的子串是 "bac", 它是 "abc" 的异位词。

```Java
class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> res = new ArrayList<>();
        int[] need = new int[26];
        int[] window = new int[26];
        for(int i=0; i<p.length(); i++) need[p.charAt(i)-'a']++;
        int right = 0;
        int left = 0;
        while(right < s.length()){
            char c = s.charAt(right);
            right++;
            window[c-'a']++;
            while(right-left > p.length()){
                char d = s.charAt(left);
                window[d-'a']--;
                left++;
            }
            if(isSame(need,window)){
                res.add(left);
            }
        }
        return res;
    }

    private boolean isSame(int[] need, int[] window){
        for(int i=0; i<26; i++){
            if(need[i] != window[i]) return false;
        }
        return true;
    }
}
```

## LeetCode76\. 最小覆盖子串

> 给定两个字符串 `s` 和 `t`，长度分别是 `m` 和 `n`，返回 s 中的 **最短窗口 **子串，使得该子串包含 `t` 中的每一个字符（**包括重复字符**）。如果没有这样的子串，返回空字符串* *`""`。
> 
> 测试用例保证答案唯一。
> 
> 

**示例 1：**

**输入：**s = "ADOBECODEBANC", t = "ABC"
**输出：**"BANC"
**解释：**最小覆盖子串 "BANC" 包含来自字符串 t 的 'A'、'B' 和 'C'。

思路解析：滑动窗口\+哈希表\+valid

1. 用right指针扩大窗口

2. 用left指针缩小窗口，直到不满足条件

3. 过程中记录最小窗口

```Java
class Solution {
    public String minWindow(String s, String t) {
        HashMap<Character, Integer> need = new HashMap<>();
        HashMap<Character, Integer> window = new HashMap<>();
        for(char c : t.toCharArray()){
            need.put(c,need.getOrDefault(c,0)+1);
        }
        int left = 0;
        int right = 0;
        int valid = 0;
        int start = 0;
        int minLen = Integer.MAX_VALUE;
        while(right < s.length()){
            char c = s.charAt(right);
            right++;
            if(need.containsKey(c)){
                window.put(c,window.getOrDefault(c,0)+1);
                if(need.get(c).equals(window.get(c))) valid++;
            }
            while(valid == need.size()){
                if(minLen > right-left){
                    minLen = right-left;
                    start = left;
                }
                char d = s.charAt(left);
                left++;      
                if(need.containsKey(d)){
                    if(window.get(d).equals(need.get(d))) valid--;
                    window.put(d,window.get(d)-1);
                }
            }
        }
        return minLen == Integer.MAX_VALUE ? "" : s.substring(start,start+minLen);
    }
}
```

```Java
class Solution {
```

```Java
public void sortColors(int[] nums) {
        int n = nums.length;
        int p0 = 0;
        int p2 = n-1;
        int cur = 0;
        while(cur <= p2){
            if(nums[cur] == 0){
                swap(nums,p0,cur);
                p0++;
                cur++;
            } else if(nums[cur] == 2){
                swap(nums,cur,p2);
                p2--;
            } else {
                cur++;
            }
        }

       nums[i] = nums[j];
       nums[j] = temp;
}
```

```Java
class Solution {
    int cnt = 0;
    public int countSubstrings(String s) {
        for(int i=0; i<s.length(); i++){
            expand(s,i,i);
            expand(s,i,i+1);
        }
        return cnt;

        while(i>=0 && j<s.length() && s.charAt(i) == s.charAt(j)){
            i--;
            j++;
            cnt++;
        }
        return;
```

> 

**示例 1：**

**输出：**2, nums = \[1,2,\_\]

```Java
class Solution {
    public int removeDuplicates(int[] nums) {
        int slow = 0;
        for(int fast = 1; fast<nums.length; fast++){
            if(nums[slow]==nums[fast]) continue;
            else {
                slow++;
                nums[slow] = nums[fast];
            }
        }
        return slow+1;
    }
}
```

## LeetCode15\. 三数之和【华为】

> 给你一个整数数组 `nums` ，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k` ，同时还满足 `nums[i] + nums[j] + nums[k] == 0` 。请你返回所有和为 `0` 且不重复的三元组。
> 
> **注意：**答案中不可以包含重复的三元组。
> 
> 

**示例 1：**

**输入：**nums = \[\-1,0,1,2,\-1,\-4\]
**输出：**\[\[\-1,\-1,2\],\[\-1,0,1\]\]
**解释：**
nums\[0\] \+ nums\[1\] \+ nums\[2\] = \(\-1\) \+ 0 \+ 1 = 0 。
nums\[1\] \+ nums\[2\] \+ nums\[4\] = 0 \+ 1 \+ \(\-1\) = 0 。
nums\[0\] \+ nums\[3\] \+ nums\[4\] = \(\-1\) \+ 2 \+ \(\-1\) = 0 。
不同的三元组是 \[\-1,0,1\] 和 \[\-1,\-1,2\] 。
注意，输出的顺序和三元组的顺序并不重要。

```Java
class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        List<List<Integer>> res = new ArrayList<>();
        int n = nums.length;
        Arrays.sort(nums);
        for(int i=0; i<n; i++){
            if(nums[i] > 0) break;
            if(i>0 && nums[i] == nums[i-1]) continue;
            int left = i+1;
            int right = n-1;
            while(left < right){
                int sum = nums[i]+nums[left]+nums[right];
                if(sum == 0){
                    res.add(Arrays.asList(nums[i],nums[left],nums[right]));
                    while(left < right && nums[left] == nums[left+1]) left++;
                    while(left < right && nums[right] == nums[right-1]) right--;
                    left++;
                    right--;
                } else if(sum < 0){
                    left++;
                } else {
                    right--;
                }
            }
        }
        return res;
    }
}
```

## LeetCode42\. 接雨水【华为】

> 给定 `n` 个非负整数表示每个宽度为 `1` 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。
> 
> 

**示例 1：**

![Image](https://internal-api-drive-stream.feishu.cn/space/api/box/stream/download/authcode/?code=Y2ViNjI1ZjhiOTI1MzZiMzMyMmU3YTkxM2NlMzYwZDBfMGZmNzBkMmI2NDQwNTMzNGEyYWQ5ZGJhZDMxNjc2NWZfSUQ6NzY0MDEwNjg5MTIzMDgwOTA1NF8xNzkzMTUxMTE4OjE3OTMyMzc1MThfVjM)

**输入：**height = \[0,1,0,2,1,0,1,3,2,1,2,1\]
**输出：**6
**解释：**上面是由数组 \[0,1,0,2,1,0,1,3,2,1,2,1\] 表示的高度图，在这种情况下，可以接 6 个单位的雨水（蓝色部分表示雨水）。 

**双指针解法：**

```Java
class Solution {
    public int trap(int[] height) {
        int left = 0;
        int leftMax = 0;
        int right = height.length-1;
        int rightMax = 0;
        int sum = 0;
        while(left < right){
            if(height[left] < height[right]){
                if(height[left] > leftMax){
                    leftMax = height[left];
                } else {
                    sum += leftMax-height[left];
                }
                left++;
            } else {
                if(height[right] > rightMax){
                    rightMax = height[right];
                } else {
                    sum += rightMax-height[right];
                }
                right--;
            }
        }
        return sum;
    }
}
```

**单调递减栈解法：**

维护一个严格单调递减的栈（栈中存储数组索引，对应高度递减）。

雨水高度 = min\(左边界高度, 右边界高度\) \- 凹槽底部高度 

雨水宽度 = 右边界索引 \- 左边界索引 \- 1 

当前层雨水量 = 雨水高度 × 雨水宽度

```Java
class Solution {
    public int trap(int[] height) {
        int sum = 0;
        // 单调递减栈：存储数组索引，对应高度递减
        Deque<Integer> stack = new LinkedList<>();

        for(int i=0; i<height.length; i++){
            // 当**当前高度大于栈顶高度时，形成凹槽，计算雨水**
            while(!stack.isEmpty() && height[i]>height[stack.peek()]){
                int bottomIndex = stack.pop();
                // 弹出后栈为空，说明没有左边界，无法接水
                if(stack.isEmpty()) break;
                // 左边界是新的栈顶，右边界是当前元素i
                int leftIndex = stack.peek();
                int rightIndex = i;

                int waterHeight = Math.min(height[leftIndex], height[rightIndex]) - height[bottomIndex];
                int waterWidth = rightIndex - leftIndex - 1;

                sum += waterHeight*waterWidth;
            }
            // 当前高度小于等于栈顶高度，入栈保持单调递减
            stack.push(i);
        }
        return sum;
    }
}
```

```Java
class Solution {
    public void rotate(int[] nums, int k) {
        int n = nums.length;
        k = k % n;
        if (k == 0) return;
        
        reverse(nums, 0, n - 1);   // 整体反转
        reverse(nums, 0, k - 1);   // 反转前k个
        reverse(nums, k, n - 1);   // 反转剩下部分
    }

    // 反转 [l, r] 闭区间
    private void reverse(int[] nums, int l, int r) {
        while (l < r) {
            int tmp = nums[l];
            nums[l] = nums[r];
            nums[r] = tmp;
            l++;
            r--;
        }
    }
}
```

```Java
class Solution {
    public int findUnsortedSubarray(int[] nums) {
        int n = nums.length;
        int left = 0;
        int right = -1;
        int min = Integer.MAX_VALUE;
        int max = Integer.MIN_VALUE;
        for(int i=0; i<n; i++){ //找右边界最后一个比max小的位置
            if(nums[i] >= max) max = nums[i];
            else right = i;
        }
        for(int i=n-1; i>=0; i--){ //找左边界第一个比min大的位置
            if(nums[i] <= min) min = nums[i];
            else left = i;
        }
        return right-left+1;
    }
}
```

```Java
class Solution {

        PriorityQueue<Integer> minHead = new PriorityQueue<>();
        for(int num : nums){
            if(minHead.size() < k){
```

```Java
        quick_sort(nums,j+1,r);
```

## LeetCode31\. 下一个排列

> 整数数组的一个 **排列**  就是将其所有成员以序列或线性顺序排列。
> 
> - 例如，`arr = [1,2,3]` ，以下这些都可以视作 `arr` 的排列：`[1,2,3]`、`[1,3,2]`、`[3,1,2]`、`[2,3,1]` 。
> 
> 整数数组的 **下一个排列** 是指其整数的下一个字典序更大的排列。更正式地，如果数组的所有排列根据其字典顺序从小到大排列在一个容器中，那么数组的 **下一个排列** 就是在这个有序容器中排在它后面的那个排列。如果不存在下一个更大的排列，那么这个数组必须重排为字典序最小的排列（即，其元素按升序排列）。
> 
> - 例如，`arr = [1,2,3]` 的下一个排列是 `[1,3,2]` 。
> 
> - 类似地，`arr = [2,3,1]` 的下一个排列是 `[3,1,2]` 。
> 
> - 而 `arr = [3,2,1]` 的下一个排列是 `[1,2,3]` ，因为 `[3,2,1]` 不存在一个字典序更大的排列。
> 
> 给你一个整数数组 `nums` ，找出 `nums` 的下一个排列。
> 
> 必须[** 原地 **](https://baike.baidu.com/item/%E5%8E%9F%E5%9C%B0%E7%AE%97%E6%B3%95)修改，只允许使用额外常数空间。
> 
> 

**示例 1：**

**输入：**nums = \[1,2,3\]
**输出：**\[1,3,2\]

**核心算法（固定 4 步模板，背下来就能秒写）**

1. **从后往前**找第一个下标 `i`，满足：`nums[i] < nums[i+1]`

2. 找不到说明整体降序，**直接反转整个数组**

3. 再**从后往前**找第一个下标 `j`，满足：`nums[j] > nums[i]`

4. 交换 `nums[i]` 和 `nums[j]`

5. **反转 i 后面所有元素**（让后面变成升序，保证最小增幅）

```Java
class Solution {
    public void nextPermutation(int[] nums) {
        int n = nums.length;
        int i = n-2;
        // 1. 从后往前找第一个 nums[i] < nums[i+1]
        while(i >=  0 && nums[i] >= nums[i+1]){
            i--;
        }

        // 2. 不是最大排列，需要找交换的 j
        if(i>=0){
            int j = n - 1;
            // 从后往前找第一个比 nums[i] 大的
            while (nums[j] <= nums[i]) {
                j--;
            }
            // 交换 i j
            swap(nums, i, j);
        }

        // 3. 反转 i 后面的部分；i<0 就反转整个数组
        reverse(nums, i + 1, n - 1);
    }
    // 交换
    private void swap(int[] nums, int a, int b) {
        int temp = nums[a];
        nums[a] = nums[b];
        nums[b] = temp;
    }

    // 反转区间 [l, r]
    private void reverse(int[] nums, int l, int r) {
        while (l < r) {
            swap(nums, l, r);
            l++;
            r--;
        }
    }
}
```

```Java
        int end = 0;
        for(int i=0; i<s.length(); i++){
```

## LeetCode451\. 根据字符出现频率排序【华为】

> 给定一个字符串 `s` ，根据字符出现的 **频率** 对其进行 **降序排序** 。一个字符出现的 **频率** 是它出现在字符串中的次数。
> 
> 返回 *已排序的字符串 *。如果有多个答案，返回其中任何一个
> 
> 

**示例 1:**

**输入: **s = "tree"
**输出: **"eert"
**解释: **'e'出现两次，'r'和't'都只出现一次。
因此'e'必须出现在'r'和't'之前。此外，"eetr"也是一个有效的答案。

**核心思路：桶排序**

利用**频率范围有限**的特性（最大频率不超过字符串长度）：

- 创建桶数组，**下标 = 频率**，桶里存对应频率的字符

- 从最高频率倒序遍历桶，依次拼接字符

```Java
class Solution {
    public String frequencySort(String s) {
        // 1. 统计每个字符的出现频率
        Map<Character, Integer> countMap = new HashMap<>();
        for (char c : s.toCharArray()) {
            countMap.put(c, countMap.getOrDefault(c, 0) + 1);
        }

        // 2. 创建桶数组：下标是频率，桶中存储对应频率的字符
        // 最大频率不超过字符串长度，所以桶大小为 s.length()+1
        List<Character>[] bucket = new List[s.length() + 1];
        for (Map.Entry<Character, Integer> entry : countMap.entrySet()) {
            int freq = entry.getValue();
            if (bucket[freq] == null) {
                bucket[freq] = new ArrayList<>();
            }
            bucket[freq].add(entry.getKey());
        }

        // 3. 从最高频率倒序遍历桶，拼接结果
        StringBuilder sb = new StringBuilder();
        for (int i = bucket.length - 1; i >= 0; i--) {
            if (bucket[i] != null) {
                for (char c : bucket[i]) {
                    // 每个字符拼接 i 次（i是它的频率）
                    sb.append(String.valueOf(c).repeat(i));
                }
            }
        }

        return sb.toString();
    }
}
```

> 
> 

**示例 1：**

![Image](https://internal-api-drive-stream.feishu.cn/space/api/box/stream/download/authcode/?code=NTAzYjkzNWM1Yjc2MDcwMjY0ODUxNjVhZDJhMWZhN2ZfOGNjZGM3Njg5MjllNDZmNTE2ODYwYzcxYWZjODgxMmJfSUQ6NzYzODk5NzA0OTExNDk3MTA3OV8xNzkzMTUxMTE4OjE3OTMyMzc1MThfVjM)

**输入：**head = \[1,2,3,4,5\], left = 2, right = 4
**输出：**\[1,4,3,2,5\]

**核心思路**

1. 用**虚拟头节点**统一处理头节点反转的特殊情况

2. 先找到反转区间的**前驱节点 pre**（第 left\-1 个节点）

3. 从 `pre.next` 开始，依次把后面的节点**头插**到 `pre` 的后面

4. 遍历到 right 节点时，中间区间自然反转完成

```Java
class Solution {
    public ListNode reverseBetween(ListNode head, int left, int right) {
        // 虚拟头节点，避免处理头节点反转的特殊情况
        ListNode dummy = new ListNode(-1);
        dummy.next = head;
        
        // 1. 找到反转区间的前驱节点 pre（第 left-1 个节点）
        ListNode pre = dummy;
        for (int i = 0; i < left - 1; i++) {
            pre = pre.next;
        }
        
        // 2. 头插法反转区间 [left, right]
        ListNode cur = pre.next; // 反转区间的第一个节点
        // 循环 right-left 次，把后面的节点依次头插到 pre 后面
        for (int i = 0; i < right - left; i++) {
            ListNode next = cur.next; // 要移动的节点
            cur.next = next.next;     // cur 指向 next 的下一个
            next.next = pre.next;     // next 指向 pre 的下一个
            pre.next = next;          // pre 指向 next
        }
        
        return dummy.next;
    }
}
```

## LeetCode146\. LRU 缓存⭐【华为】

> 请你设计并实现一个满足  [LRU \(最近最少使用\) 缓存](https://baike.baidu.com/item/LRU) 约束的数据结构。
> 
> 实现 `LRUCache` 类：
> 
> - `LRUCache(int capacity)` 以 **正整数** 作为容量 `capacity` 初始化 LRU 缓存
> 
> - `int get(int key)` 如果关键字 `key` 存在于缓存中，则返回关键字的值，否则返回 `-1` 。
> 
> - `void put(int key, int value)` 如果关键字 `key` 已经存在，则变更其数据值 `value` ；如果不存在，则向缓存中插入该组 `key-value` 。如果插入操作导致关键字数量超过 `capacity` ，则应该 **逐出** 最久未使用的关键字。
>

> 
> 

**示例：**

**输入**
\["LRUCache", "put", "put", "get", "put", "get", "put", "get", "get", "get"\]
\[\[2\], \[1, 1\], \[2, 2\], \[1\], \[3, 3\], \[2\], \[4, 4\], \[1\], \[3\], \[4\]\]
**输出**
\[null, null, null, 1, null, \-1, null, \-1, 3, 4\]

**解释**
LRUCache lRUCache = new LRUCache\(2\);
lRUCache\.put\(1, 1\); // 缓存是 \{1=1\}
lRUCache\.put\(2, 2\); // 缓存是 \{1=1, 2=2\}
lRUCache\.get\(1\);    // 返回 1
lRUCache\.put\(3, 3\); // 该操作会使得关键字 2 作废，缓存是 \{1=1, 3=3\}
lRUCache\.get\(2\);    // 返回 \-1 \(未找到\)
lRUCache\.put\(4, 4\); // 该操作会使得关键字 1 作废，缓存是 \{4=4, 3=3\}
lRUCache\.get\(1\);    // 返回 \-1 \(未找到\)
lRUCache\.get\(3\);    // 返回 3
lRUCache\.get\(4\);    // 返回 4

**思路解析：双向链表\+哈希表**

```Java
class DLinkedNode {
    int key;
    int val;
    DLinkedNode next;
    DLinkedNode prev;
    public DLinkedNode(){}
    public DLinkedNode(int key, int val){
        this.key = key;
        this.val = val;
    }
}
class LRUCache {
    DLinkedNode head;
    DLinkedNode tail;
    int capacity;
    int size;
    HashMap<Integer, DLinkedNode> cache;

    public LRUCache(int capacity) {
        head = new DLinkedNode();
        tail = new DLinkedNode();
        head.next = tail;
        tail.prev = head;
        this.capacity = capacity;
        size = 0;
        cache = new HashMap<>();
    }
    
    public int get(int key) {
        DLinkedNode node = cache.get(key);
        if(node == null){
            return -1;
        } else {
            moveToHead(node);
            return node.val;
        }
    }
    
    public void put(int key, int value) {
        DLinkedNode node = cache.get(key);
        if(node == null){
            DLinkedNode newnode = new DLinkedNode(key,value);
            addToHead(newnode);
            cache.put(key,newnode);
            size++;
            if(size > capacity){
                DLinkedNode deNode = removeTailNode();
                cache.remove(deNode.key);
                size--;
            }
        } else {
            node.val = value;
            moveToHead(node);
        }
    }
    // 用于新节点创建和被moveToHead()调用
    private void addToHead(DLinkedNode node){
        node.next = head.next;
        node.prev = head;
        head.next.prev = node;
        head.next = node;
    }
    private void removeNode(DLinkedNode node){
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }
    public void moveToHead(DLinkedNode node){
        removeNode(node);
        addToHead(node);
    }
    public DLinkedNode removeTailNode(){
        DLinkedNode res = tail.prev;
        removeNode(res);
        return res;
    }
}
```

```Java
        if(n == 1) return nums[0];

        }
```

> 
> 

**示例 1：**

```Plain Text
**输入：**coins = [1, 2, 5], amount = 11**输出：**3 
**解释：**11 = 5 + 5 + 1
```

**核心思路：完全背包 动态规划**

定义：`dp[i]` = 凑出金额 `i` 需要的**最少硬币数**

1. 初始化

    - `dp` 数组初始填一个大数（代表暂时凑不出）

    - `dp[0] = 0`：金额 0 不需要硬币

2. 状态转移对每个金额 `i`，遍历每种硬币：若硬币面额 ≤ 当前金额：`dp[i] = Math.min(dp[i], dp[i - coin] + 1)`

```Java
class Solution {
    public int coinChange(int[] coins, int amount) {
        // 初始化dp，设为一个不可能的大数
        int[] dp = new int[amount + 1];
        int INF = amount + 1;
        for (int i = 1; i <= amount; i++) {
            dp[i] = INF;
        }
        dp[0] = 0;

        // 遍历每个金额
        for (int i = 1; i <= amount; i++) {
            // 遍历每种硬币
            for (int coin : coins) {
                if (coin <= i) {
                    dp[i] = Math.min(dp[i], dp[i - coin] + 1);
                }
            }
        }

        // 还是INF说明凑不出
        return dp[amount] == INF ? -1 : dp[amount];
    }
}
```

1. 前 `j` 个字符可以拆分：`dp[j] == true`

2. `j ~ i` 这一段子串在字典中

```Java
class Solution {
    public boolean wordBreak(String s, List<String> wordDict) {
        Set<String> set = new HashSet<>(wordDict);
        int n = s.length();
        boolean[] dp = new boolean[n + 1];
        dp[0] = true;  // 空串合法

        for (int i = 1; i <= n; i++) {
            // 枚举分割点 j
            for (int j = 0; j < i; j++) {
                if (dp[j] && set.contains(s.substring(j, i))) {
                    dp[i] = true;
                    break;
                }
            }
        }
        return dp[n];
    }
}
```

**初始化：**

- `dp[0][j] = j`：将空字符串转换成 `word2` 的前 `j` 个字符，需要插入 `j` 个字符

- `dp[i][0] = i`：将 `word1` 的前 `i` 个字符转换成空字符串，需要删除 `i` 个字符

**状态转移方程：**

- 当前字符相等

如果 `word1[i-1] == word2[j-1]`（注意索引对应关系），说明这两个字符不需要任何操作，直接继承前一个子问题的解：

- 当前字符不相等

如果 `word1[i-1] != word2[j-1]`，我们可以选择三种操作中的任意一种，取操作次数最少的那个：

1. 替换操作：将 `word1[i-1]` 替换成 `word2[j-1]`，操作次数为 `dp[i-1][j-1] + 1`

2. 删除操作：删除 `word1[i-1]`，操作次数为 `dp[i-1][j] + 1`

3. 插入操作：在 `word1` 后面插入一个 `word2[j-1]`，操作次数为 `dp[i][j-1] + 1`

```Java
class Solution {
    public int minDistance(String word1, String word2) {
        int m = word1.length();
        int n = word2.length();
        // 创建dp数组，大小为(m+1)x(n+1)
        int[][] dp = new int[m + 1][n + 1];       
        // 初始化第一列：word2为空，需要删除word1的所有字符
        for (int i = 0; i <= m; i++) {
            dp[i][0] = i;
        }      
        // 初始化第一行：word1为空，需要插入word2的所有字符
        for (int j = 0; j <= n; j++) {
            dp[0][j] = j;
        }      
        // 填充dp数组
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    // 当前字符相等，不需要操作
                    dp[i][j] = dp[i - 1][j - 1];
                } else {
                    // 当前字符不相等，取三种操作的最小值+1
                    int replace = dp[i - 1][j - 1]; // 替换
                    int delete = dp[i - 1][j];      // 删除
                    int insert = dp[i][j - 1];      // 插入
                    dp[i][j] = Math.min(Math.min(replace, delete), insert) + 1;
                }
            }
        }  
        // 返回最终结果
        return dp[m][n];
    }
}
```

```Java
        List<String> res = new ArrayList<>();
        int n = s.length();

        f(res, 0, new ArrayList<>(), s);
        
        return res;

    public void f(List<String> res, int begin, List<String> curr, String s){
        if(curr.size() == 4 && begin == s.length()){

            if(Integer.parseInt(segment) > 255) continue;

            f(res, end, curr, s);
```

    - `strStack`：存括号前已拼接的字符串

2. 两个临时变量：

    - `curNum`：记录当前累积数字（支持多位数）

    - `curStr`：记录当前正在拼接的字符串

3. 遍历字符分四种情况：

    - **数字**：累积计算多位数

    - **字母**：直接拼到 `curStr`

    - **左括号 ****`[`**：把当前数字、当前字符串压栈，重置临时变量

    - **右括号 ****`]`**：弹出次数、弹出前缀字符串，把当前字符串重复次数次，拼到前缀上

```Java
class Solution {
    public String decodeString(String s) {
        Stack<Integer> numStack = new Stack<>();
        Stack<String> strStack = new Stack<>();
        int curNum = 0;
        StringBuilder curStr = new StringBuilder();
        for(char c : s.toCharArray()){
            // 1. 数字：处理多位数
            if(Character.isDigit(c)){
                curNum = curNum*10+(c-'0');
            } // 2. 左括号：入栈，重置
            else if(c == '['){ 
                numStack.push(curNum);
                strStack.push(curStr.toString());
                curNum = 0;
                curStr = new StringBuilder();
            } // 3. 右括号：出栈、重复拼接
            else if (c == ']') {
                int k = numStack.pop();
                String preStr = strStack.pop();
                // 把当前字符串重复 k 次
                StringBuilder temp = new StringBuilder(preStr);
                for (int i = 0; i < k; i++) {
                    temp.append(curStr);
                }
                curStr = temp;
            } else { // 4. 普通字符
                curStr.append(c);
            }

        }
        return curStr.toString();
    }
}
```

> 给定一个整数数组 `temperatures` ，表示每天的温度，返回一个数组 `answer` ，其中 `answer[i]` 是指对于第 `i` 天，下一个更高温度出现在几天后。如果气温在这之后都不会升高，请在该位置用 `0` 来代替。
> 
> 

**示例 1:**

**输入:** temperatures = \[73,74,75,71,69,72,76,73\]
**输出:** \[1,1,4,2,1,1,0,0\]

**核心思路：单调递减栈**

经典单调栈模板题：

- 栈中只存**数组下标**，保持栈对应温度**从底到顶递减**

- 遍历每一天下标 `i`：

    1. 只要栈不为空 **且 当前温度 \> 栈顶下标对应的温度**：

        - 弹出栈顶下标 `top`

        - `ans[top] = i - top` 算出间隔天数

    2. 把当前下标 `i` 压入栈

```Java
class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        int n = temperatures.length;
        int[] res = new int[n];
        Stack<Integer> stack = new Stack<>();

        for (int i = 0; i < n; i++) {
            // 单调递减栈：遇到更大值，弹出并计算天数
            while (!stack.isEmpty() && temperatures[i] > temperatures[stack.peek()]) {
                int top = stack.pop();
                res[top] = i - top;
            }
            stack.push(i);
        }
        return res;
    }
}
```

## LeetCode23\. 合并K个升序链表【华为】

> 给你一个链表数组，每个链表都已经按升序排列。
> 
> 请你将所有链表合并到一个升序链表中，返回合并后的链表。
> 
> 

**示例 1：**

**输入：**lists = \[\[1,4,5\],\[1,3,4\],\[2,6\]\]
**输出：**\[1,1,2,3,4,4,5,6\]
**解释：**链表数组如下：
\[
  1\-\>4\-\>5,
  1\-\>3\-\>4,
  2\-\>6
\]
将它们合并到一个有序链表中得到。
1\-\>1\-\>2\-\>3\-\>4\-\>4\-\>5\-\>6

**核心思路**

利用**小顶堆**每次快速获取 k 个链表中当前最小的节点：

1. 初始化小顶堆，将所有非空链表的头节点加入堆中

2. 创建哑节点（dummy）作为结果链表的头，方便构建

3. 循环取出堆顶的最小节点，加入结果链表

4. 如果该节点还有下一个节点，将下一个节点加入堆中

5. 直到堆为空，返回哑节点的下一个节点

```Java
class Solution {
    public ListNode mergeKLists(ListNode[] lists) {
        // 边界处理：空数组直接返回null
        if (lists == null || lists.length == 0) {
            return null;
        }
        // 初始化小顶堆，自定义比较器按节点值升序排列
        PriorityQueue<ListNode> minHeap = new PriorityQueue<>((a, b) -> a.val - b.val);
        // 将所有非空链表的头节点加入堆
        for (ListNode head : lists) {
            if (head != null) {
                minHeap.offer(head);
            }
        }
        ListNode dummy = new ListNode(-1);
        ListNode curr = dummy;

        // 循环取出最小节点
        while (!minHeap.isEmpty()) {
            ListNode minNode = minHeap.poll();
            curr.next = minNode;
            curr = curr.next;
            // 如果该节点还有下一个节点，加入堆中
            if (minNode.next != null) {
                minHeap.offer(minNode.next);
            }
        }
        return dummy.next;
    }
}
```

```Java
class Solution {
    public int jump(int[] nums) {
        int n = nums.length;
        if(n<=1) return 0;
        // steps : 跳跃次数
        int steps = 0;
        // currentEnd : 当前这一步能达到的最远距离
        int currentEnd = 0;

            if(i == currentEnd){
                steps++;
                currentEnd = maxReach;
            }
        }
        return steps;
    }
}
```

## LeetCode406\. 根据身高重建队列【华为】

> 假设有打乱顺序的一群人站成一个队列，数组 `people` 表示队列中一些人的属性（不一定按顺序）。每个 `people[i] = [h(i), k(i)]` 表示第 `i` 个人的身高为 `h(i)` ，前面 **正好** 有 `k(i)`\( \)个身高大于或等于 `h(i)` 的人。
> 
> 请你重新构造并返回输入数组 `people` 所表示的队列。返回的队列应该格式化为数组 `queue` ，其中 `queue[j] = [h(j), k(j)]` 是队列中第 `j` 个人的属性（`queue[0]` 是排在队列前面的人）。
> 
> 

**示例 1：**

**输入：**people = \[\[7,0\],\[4,4\],\[7,1\],\[5,0\],\[6,1\],\[5,2\]\]
**输出：**\[\[5,0\],\[7,0\],\[5,2\],\[6,1\],\[4,4\],\[7,1\]\]
**解释：**
编号为 0 的人身高为 5 ，没有身高更高或者相同的人排在他前面。
编号为 1 的人身高为 7 ，没有身高更高或者相同的人排在他前面。
编号为 2 的人身高为 5 ，有 2 个身高更高或者相同的人排在他前面，即编号为 0 和 1 的人。
编号为 3 的人身高为 6 ，有 1 个身高更高或者相同的人排在他前面，即编号为 1 的人。
编号为 4 的人身高为 4 ，有 4 个身高更高或者相同的人排在他前面，即编号为 0、1、2、3 的人。
编号为 5 的人身高为 7 ，有 1 个身高更高或者相同的人排在他前面，即编号为 1 的人。
因此 \[\[5,0\],\[7,0\],\[5,2\],\[6,1\],\[4,4\],\[7,1\]\] 是重新构造后的队列。

**思路解析：**

先按**身高降序排序，身高相同则按 k 值升序排序**；然后依次将每个人插入到队列的第 k 个位置。

**为什么这个策略有效？**

1. **高个子优先**：当我们处理一个人时，所有已经在队列中的人身高都大于或等于他。因此，将他插入到第 k 个位置，正好满足 "前面有 k 个身高大于等于他的人" 的条件。

2. **矮个子不影响高个子**：插入矮个子时，不会改变已经排好的高个子之间的相对顺序，也不会影响高个子的 k 值（因为矮个子的身高小于高个子，不会被计入高个子的 k 值）。

3. **身高相同按 k 升序**：如果两个人身高相同，k 值小的应该排在前面。因为身高相同的人会互相计入对方的 k 值，先插入 k 小的，后插入 k 大的，才能保证两者的 k 值都正确。

```Java
class Solution {
    public int[][] reconstructQueue(int[][] people) {
        // 1. 排序：身高降序，身高相同则k值升序
        Arrays.sort(people, (a, b) -> {
            if (a[0] != b[0]) {
                // 身高不同，降序排列
                return b[0] - a[0];
            } else {
                // 身高相同，k值升序排列
                return a[1] - b[1];
            }
        });

        // 2. 依次插入到第k个位置
        List<int[]> queue = new ArrayList<>();
        for (int[] person : people) {
            queue.add(person[1], person);
        }

        // 3. 转换为数组返回
        return queue.toArray(new int[people.length][]);
    }
}
```

```Java
    public int leastInterval(char[] tasks, int n) {
        int[] cnt = new int[26];
        for(char c : tasks) cnt[c-'A']++;
        int maxFreq = 0;
        for(int num : cnt){
            maxFreq = Math.max(maxFreq,num);
        }
        int maxCount = 0;

        for(int num : cnt){
            if(num == maxFreq) maxCount++;
        }
        int time = (maxFreq-1)*(n+1)+maxCount;
        return Math.max(time,tasks.length);
    }

            }
```
```Java
        }

    private void bfs(char[][] grid, int i, int j){
        // 队列存储待访问的陆地坐标（用int数组存储行和列）

        queue.offer(new int[]{i,j});
```

## LeetCode207\. 课程表【华为】

> 你这个学期必须选修 `numCourses` 门课程，记为 `0` 到 `numCourses - 1` 。
> 
> 在选修某些课程之前需要一些先修课程。 先修课程按数组 `prerequisites` 给出，其中 `prerequisites[i] = [a(i), b(i)]` ，表示如果要学习课程 `a(i)` 则 **必须** 先学习课程  `b(i)`\( \)。
> 
> - 例如，先修课程对 `[0, 1]` 表示：想要学习课程 `0` ，你需要先完成课程 `1` 。
> 
> 请你判断是否可能完成所有课程的学习？如果可以，返回 `true` ；否则，返回 `false` 。、
> 
> 

**示例 1：**

**输入：**numCourses = 2, prerequisites = \[\[1,0\]\]
**输出：**true
**解释：**总共有 2 门课程。学习课程 1 之前，你需要完成课程 0 。这是可能的。

**思路解析：**

拓扑排序

判断**有向图中是否存在环**。如果存在环，说明有课程的先修关系形成了死循环，无法完成所有课程；如果不存在环（即图是有向无环图 DAG），则可以完成。

**BFS:**

构建图的**邻接表**和**入度数组**

将所有入度为 0 的节点（没有先修课的课程）加入队列

依次取出队列中的节点，遍历它的所有后继节点，将后继节点的入度减 1

如果某个后继节点的入度变为 0，说明它的所有先修课都已完成，加入队列

最后统计已访问的节点数：

- 若等于总课程数 → 无环，返回`true`

- 若小于总课程数 → 有环，返回`false`

```Java
class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        // 1. 构建邻接表和入度数组
        ArrayList<Integer>[] adjacency = new ArrayList[numCourses];
        int[] inDegree = new int[numCourses];
        
        // 初始化邻接表
        for (int i = 0; i < numCourses; i++) {
            adjacency[i] = new ArrayList<>();
        }
        
        // 填充邻接表和入度数组
        for (int[] pre : prerequisites) {
            int course = pre[0];    // 要学的课程
            int prerequisite = pre[1]; // 先修课程
            adjacency[prerequisite].add(course); // 边：prerequisite → course
            inDegree[course]++;
        }
        
        // 2. 初始化队列，加入所有入度为0的节点
        Queue<Integer> queue = new LinkedList<>();
        for (int i = 0; i < numCourses; i++) {
            if (inDegree[i] == 0) {
                queue.offer(i);
            }
        }
        
        // 3. BFS遍历
        int visitedCount = 0;
        while (!queue.isEmpty()) {
            int curr = queue.poll();
            visitedCount++;
            
            // 遍历当前节点的所有后继节点
            for (int next : adjacency[curr]) {
                inDegree[next]--;
                // 入度变为0，说明所有先修课已完成
                if (inDegree[next] == 0) {
                    queue.offer(next);
                }
            }
        }
        
        // 4. 判断是否所有课程都被访问过
        return visitedCount == numCourses;
    }
}
```

DFS:

通过递归遍历每个节点，用**状态数组**记录节点的访问状态，检测是否存在环：

- 状态`0`：未访问

- 状态`1`：正在访问（在当前递归栈中）

- 状态`2`：已访问完成

```Java
class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        // 1. 构建邻接表
        ArrayList<Integer>[] adjacency = new ArrayList[numCourses];
        for (int i = 0; i < numCourses; i++) {
            adjacency[i] = new ArrayList<>();
        }
        for (int[] pre : prerequisites) {
            adjacency[pre[1]].add(pre[0]);
        }
        // 2. 状态数组：0=未访问，1=正在访问，2=已访问
        int[] status = new int[numCourses];
        // 3. 遍历所有节点
        for (int i = 0; i < numCourses; i++) {
            if (hasCycle(i, adjacency, status)) {
                return false;
            }
        }
        return true;
    }
    // 检测以curr为起点的路径是否存在环
    private boolean hasCycle(int curr, ArrayList<Integer>[] adjacency, int[] status) {
        // 如果当前节点正在访问，说明存在环
        if (status[curr] == 1) {
            return true;
        }
        // 如果当前节点已访问完成，说明无环
        if (status[curr] == 2) {
            return false;
        }
        // 标记为正在访问
        status[curr] = 1;
        // 递归遍历所有后继节点
        for (int next : adjacency[curr]) {
            if (hasCycle(next, adjacency, status)) {
                return true;
            }
        }
        // 所有后继节点遍历完成，标记为已访问
        status[curr] = 2;
        return false;
    }
}
```

```Java
class Solution {
    // 四个方向：上、下、左、右
    private static final int[][] DIRECTIONS = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};

    public int maxAreaOfIsland(int[][] grid) {
        // 边界处理：空网格直接返回0
        if (grid == null || grid.length == 0 || grid[0].length == 0) {
            return 0;
        }
        int rowCount = grid.length;
        int colCount = grid[0].length;
        int maxArea = 0;

        // 遍历网格每一个单元格
        for (int i = 0; i < rowCount; i++) {
            for (int j = 0; j < colCount; j++) {
                // 发现未访问的陆地，启动BFS计算面积
                if (grid[i][j] == 1) {
                    int currentArea = bfs(grid, i, j, rowCount, colCount);
                    maxArea = Math.max(maxArea, currentArea);
                }
            }
        }
        return maxArea;
    }
    // BFS计算单个岛屿的面积，并标记所有连通陆地为已访问
    private int bfs(int[][] grid, int startRow, int startCol, int rowCount, int colCount) {
        Queue<int[]> queue = new LinkedList<>();
        queue.offer(new int[]{startRow, startCol});
        grid[startRow][startCol] = 0; // 入队即标记为已访问

        int area = 0;

        while (!queue.isEmpty()) {
            int[] curr = queue.poll();
            area++; // 每出队一个节点，面积+1

            int currRow = curr[0];
            int currCol = curr[1];

            // 遍历四个方向
            for (int[] dir : DIRECTIONS) {
                int newRow = currRow + dir[0];
                int newCol = currCol + dir[1];

                // 检查新坐标是否合法且是未访问的陆地
                if (newRow >= 0 && newRow < rowCount 
                    && newCol >= 0 && newCol < colCount 
                    && grid[newRow][newCol] == 1) {
                    queue.offer(new int[]{newRow, newCol});
                    grid[newRow][newCol] = 0; // 入队即标记，避免重复入队
                }
            }
        }

        return area;
    }
```

```Java
    public int maxAreaOfIsland(int[][] grid) {
        if (grid == null || grid.length == 0 || grid[0].length == 0) {
            return 0;
        }

        int rowCount = grid.length;
        int colCount = grid[0].length;
        int maxArea = 0;

        for (int i = 0; i < rowCount; i++) {
            for (int j = 0; j < colCount; j++) {
                if (grid[i][j] == 1) {

                    maxArea = Math.max(maxArea, currentArea);
                }
            }
        }

        return maxArea;
    }
    // DFS递归计算单个岛屿的面积
    private int dfs(int[][] grid, int row, int col, int rowCount, int colCount) {
        // 递归终止条件：坐标越界 或 不是未访问的陆地
        if (row < 0 || row >= rowCount || col < 0 || col >= colCount || grid[row][col] == 0) {

        for (int[] dir : DIRECTIONS) {
            area += dfs(grid, row + dir[0], col + dir[1], rowCount, colCount);
        }

        return area;
```

```Java
class Solution {
```

```Java
    public int diameterOfBinaryTree(TreeNode root) {
        dfs(root);
        return max;
    }

        int right_deep = dfs(root.right);
```

> 给你二叉树的根节点 `root` ，返回其节点值的 **层序遍历** 。 （即逐层地，从左到右访问所有节点）。

```Java
class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> res = new ArrayList<>();
        Deque<TreeNode> queue = new LinkedList<>();
        if(root == null) return res;
        queue.offer(root);

        while(!queue.isEmpty()){
            List<Integer> level = new ArrayList<>();
            int size = queue.size();
            for(int i=0; i<size; i++){
                TreeNode cur = queue.poll();
                level.add(cur.val);
                if(cur.left != null) queue.offer(cur.left);
                if(cur.right != null) queue.offer(cur.right);
            }
            res.add(level);
        }
        return res;
    }
}
```

```Java
     public TreeNode sortedArrayToBST(int[] nums) {
        return buildTree(nums, 0, nums.length - 1);
    }

    // 递归构建[l,r]区间的平衡BST
    private TreeNode buildTree(int[] nums, int l, int r) {
        // 递归终止
        if (l > r) return null;

        // 取中点做根，避免溢出
        int mid = l + (r - l) / 2;
        TreeNode root = new TreeNode(nums[mid]);

        root.right = buildTree(nums, mid + 1, r);

        return root;
    }
```

```Java
        if(root == null) return 0;
        return countPath(root,targetSum)+pathSum(root.left,targetSum)+pathSum(root.right,targetSum);
```

```Java
            return root;

        return left!=null ? left : right;
    }
}
```

## LeetCode124\. 二叉树的最大路径和【华为】

> 二叉树中的** 路径** 被定义为一条节点序列，序列中每对相邻节点之间都存在一条边。同一个节点在一条路径序列中 **至多出现一次** 。该路径** 至少包含一个 **节点，且不一定经过根节点。
> 
> **路径和** 是路径中各节点值的总和。
> 
> 给你一个二叉树的根节点 `root` ，返回其 **最大路径和** 。
> 
> 

**示例 1：**

![Image](https://internal-api-drive-stream.feishu.cn/space/api/box/stream/download/authcode/?code=NjhkY2MzZDMzZmNkOWJkYjMxODcwMmMxNDkxZmU4ZTVfODcwNTdlMzdiYWVhYmQ1MjVlZjQwMWRhYmQ4ZTk2MWNfSUQ6NzY0MDEzNzU1NDAzMzAzNjI2NF8xNzkzMTUxMTE4OjE3OTMyMzc1MThfVjM)

**输入：**root = \[\-10,9,20,null,null,15,7\]
**输出：**42
**解释：**最优路径是 15 \-\> 20 \-\> 7 ，路径和为 15 \+ 20 \+ 7 = 42

**思路解析：后序遍历，对于每个节点，计算以该节点为最高点的最大路径和**

```Java
class Solution {
    private int maxSum;
    public int maxPathSum(TreeNode root) {
        maxSum = Integer.MIN_VALUE;
        dfs(root);
        return maxSum;
    }

    private int dfs(TreeNode root){
        if(root == null) return 0;
        // 左子树最大贡献，负数则不取
        int left = Math.max(dfs(root.left),0);
        int right = Math.max(dfs(root.right),0);

        int current = left + root.val + right;
        maxSum = Math.max(maxSum, current);
        // 向上返回，只能选一条链
        return root.val + Math.max(left,right);
    }
}
```
